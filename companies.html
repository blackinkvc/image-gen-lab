01

产业链五层

越往下越重资产、越集中；越往上越分散、越贴近用户。

① 算力 Silicon

GPU / TPU / 加速卡 / 网络 / 先进封装。技术壁垒最高，供给决定上层节奏。

② 云 Cloud

把算力租出去，同时提供模型托管与 Agent 运行时。规模效应明显。

③ 基模 Models

预训练成本极高，头部收敛；开放权重让第二梯队得以存在。

④ 工具 / Agent Tools

编码、浏览、检索、工作流编排。贴近场景，容易被上层整合。

⑤ 应用 Apps

助手、办公、内容生产、行业软件。用户在这里感知 AI，也在这里付费。

纵向整合 Cross-layer

云 + 基模 + 芯片自研的公司在成本与迭代速度上占优，但资本开支也最重。

03

合作与资本

这一层的绑定关系，决定了很多「独立公司」的实际自由度：

Microsoft ↔ OpenAI云资源、模型独占期与收入分成长期绑定，条款多次调整。
Amazon ↔ Anthropic累计投资达 80 亿美元量级，同时是主要云与芯片供应方。
Google ↔ Anthropic既是投资方，也是云与 TPU 供应方，同时Gemini 是直接竞品。
NVIDIA ↔ 多家通过投资与优先供货，把客户变成生态的一部分。
云厂自研芯片Google TPU、Amazon Trainium、Microsoft Maia，目的都是降低单位推理成本。
主权 AI欧洲、中东、东南亚都在建本地算力与本地模型，采购逻辑不同于纯商业市场。

具体金额与条款以公开披露为准；本页只保留量级，不写精确数字，避免过期。

04

观察指标

判断一家公司在 AI 周期里的真实位置，可以盯这几项，而不是发布会声量：

算力合同 供给

长期算力采购与自建集群规模，决定下一代模型能不能按时训出来。

推理成本 单位经济

每百万 token 的成本曲线，决定应用能不能规模化。

开发者份额 生态

API 调用与开源下载量，比日活更能反映底层锁定。

企业续费 收入质量

试点转生产的比例，决定收入是泡沫还是一次性预算。
