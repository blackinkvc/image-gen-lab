三条结论 / VERDICT

  1. 闭源旗舰的节奏是「合并」。快慢思考、多模态、工具调用逐渐收进一个默认模型，单独发布的推理模型越来越少。
  2. 开放权重追得很紧，但差一个身位。头部开放模型在通用对话上接近旗舰，长程 Agent 与多模态仍有差距；许可证差异比参数差异更影响可用性。
  3. 参数规模不再是唯一叙事。MoE 把总参数与激活参数拆开，稀疏化、注意力和数据配比比堆参数更能解释实际体验。

02

三条主线，一个转折

按时间看是一串发布，按机制看只有三条线在同时推进，外加 2025 年的一次转折。 理解这四条，比记住模型名有用。

稠密 → MoE 2023 →

总参数继续涨，但每个 token 只激活一部分专家。好处是同成本下容量更大， 代价是显存占用按总参数算、路由与负载均衡变复杂。

预训练 → 后训练 2024 →

预训练决定知识上限，SFT 与偏好优化决定「好不好用」。 2025 年的增量更多来自可验证奖励的强化学习，而不是更大的预训练语料。

文本 → 原生多模态 2024 →

从「拼一个视觉编码器」转向音频、图像、视频在同一套表示里训练。 语音端到端是分水岭：延迟和语气都变了。

推理即产品 2024-09 →

o1 之后，推理不再是隐藏步骤，而是可以按 token 售卖的商品。 GPT-5 又把这条路收回默认路由，说明「单独一个推理模型」只是过渡形态。

判断一条发布是不是「真进展」，可以看它是否改变了默认配置：默认上下文长度、默认是否思考、默认是否带工具。

03

选型维度

不按榜单选，按约束选。以下六项按对实际成本的影响排序：

许可证开放权重不等于可商用，先看条款再看能力。
上下文标称长度 ≠ 有效长度，长文任务要实测检索位置。
单价按输入 / 输出分别计，推理模型的输出 token 往往更多。
吞吐Agent 场景看并发与首 token 延迟，不只看单次质量。
工具调用结构化输出稳定性决定 Agent 能不能落地。
可部署性能不能私有化、量化后掉多少，决定长期成本。
